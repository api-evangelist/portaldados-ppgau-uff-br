# Portal de Dados Urbanos PPGAU UFF - Open data portal for Urban Resarch (portaldados-ppgau-uff-br)

Portal de Dados Urbanos PPGAU UFF - Open data portal for Urban Resarch is a open data portal open-data portal for Brazil running **CKAN**, exposing a standardized catalog API over ~120 datasets.
